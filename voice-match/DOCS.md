# Voice Match

Верифікація голосу для Home Assistant: перевіряє спікера, чистить фон, шле аудіо на Wyoming STT.

## Швидкий старт

1. Запустіть **Wyoming OpenAI STT** (або інший Wyoming STT).
2. Upstream: `tcp://homeassistant:10300` (або «Сканувати» в UI).
3. Бічне меню **Voice Match**:
   - ім’я спікера (латиниця);
   - **запис з мікрофона** або завантаження файлів;
   - «Перевірити всі зразки» → видаліть погані;
   - **Запустити enrollment**;
   - **Restart** (кнопка в UI або на сторінці аддона).
4. Wyoming Protocol → порт **10350** → pipeline STT = Voice Match.

## Запис у UI

1. Запис → говоріть 3–10 сек → Стоп  
2. Перевірити запис  
3. Зберегти або Видалити  
4. Повторіть 3–5 разів  
5. Enrollment → Restart  

Так, **enrollment потрібен** після зразків — інакше voiceprint не оновиться.  
Після enrollment обов’язковий **Restart**.

## Будь-який голос

Вимкніть **Вимагати збіг голосу** у Configuration — аддон працює як проксі без перевірки.

## Пороги

| Ситуація | verify | extraction |
|----------|--------|------------|
| За замовчуванням | 0.40 | 0.35 |
| Часто відхиляє мене | 0.32–0.35 | 0.28–0.32 |
| Чужий голос проходить | 0.48–0.55 | 0.35–0.40 |

Пороги не виправляють помилки тексту — лише хто проходить і наскільки чиститься фон.
