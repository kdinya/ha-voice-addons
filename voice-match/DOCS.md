# Voice Match

Проксі з **верифікацією голосу** для Home Assistant.

Перевіряє, що говорить саме зареєстрована людина, прибирає фон (ТБ, інші голоси)
і лише тоді надсилає очищене аудіо на ваш Wyoming STT (OpenAI/Groq, Faster Whisper тощо).

## Швидкий старт

1. Встановіть і запустіть будь-який Wyoming STT  
   (рекомендовано **Wyoming OpenAI STT** з цього ж репозиторію).
2. Configuration:
   - **Адреса Wyoming STT** → `tcp://homeassistant:10300`  
     (або натисніть «Сканувати Wyoming STT» у веб-інтерфейсі)
   - **Мови** → `uk` або `uk,en`
3. Start аддона.
4. Бічне меню **Voice Match** → завантажте 3–5 записів голосу → enrollment.
5. **Restart** аддона.
6. Settings → Devices & Services → Wyoming Protocol → порт **10350**.
7. Voice Assistants → pipeline → Speech-to-Text → **Voice Match**.

## Якщо «чує не те, що кажу»

Це **не** пороги верифікації голосу. Це якість STT (Groq / OpenAI / Whisper).

Що допомагає:
- Мова в pipeline і в аддоні STT має збігатися з реальною (`uk`).
- Для Groq: модель `whisper-large-v3-turbo` (швидко) або `whisper-large-v3` (точніше).
- Говоріть чіткіше, ближче до мікрофона; менше шуму.
- У Voice Match `extraction_threshold` трохи нижче (0.28–0.32), якщо «обрізає» слова.

Пороги Voice Match впливають лише на:
- **verify_threshold** — чи приймається ваш голос
- **extraction_threshold** — наскільки жорстко відсікається фон

## Рекомендовані пороги

| Ситуація | verify_threshold | extraction_threshold |
|----------|------------------|----------------------|
| За замовчуванням | 0.40 | 0.35 |
| Часто відхиляє мій голос | 0.32–0.35 | 0.28–0.32 |
| Чужий голос інколи проходить | 0.48–0.55 | 0.35–0.40 |
| Багато шуму ТБ | 0.40 | 0.38–0.45 |

## Кнопка «Сканувати Wyoming STT»

У Ingress UI (бічне меню) є кнопка пошуку відкритих портів Wyoming
на типових хостах (`homeassistant`, `localhost`…) і портах 10300–10500.
Скопіюйте URI → Configuration → Адреса Wyoming STT → Restart.

## Enrollment

- 3–5 файлів, 3–10 секунд кожен
- Різний тон / відстань / гучність
- Без сильного фону
- Ім’я латиницею: `a-z0-9_-`

Після успішного enrollment **обов’язково Restart** аддона.
