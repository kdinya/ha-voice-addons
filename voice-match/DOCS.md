# Voice Match

Верифікація голосу для Home Assistant: перевіряє, що говорить саме ви, прибирає фон і чужі голоси, після чого надсилає очищене аудіо на Wyoming STT (наприклад, **Wyoming OpenAI STT**).

Аддон працює як проксі в ланцюжку:

```
Мікрофон → Voice Match (порт 10350) → Wyoming STT (наприклад 10300) → Home Assistant
```

## Швидкий старт

1. Встановіть і запустіть **Wyoming OpenAI STT** (або інший Wyoming STT).
2. У Configuration Voice Match вкажіть **upstream_uri** (`Адреса Wyoming STT`):  
   `tcp://homeassistant:10300`  
   або натисніть **Сканувати** у веб-інтерфейсі та скопіюйте знайдений URI.
3. Відкрийте бічне меню **Voice Match** (Ingress):
   - оберіть спікера зі списку або введіть нове ім’я латиницею;
   - запишіть 3–5 зразків з мікрофона **або** завантажте файли;
   - натисніть **Перевірити всі зразки** і видаліть погані (bad / weak);
   - **Enrollment** → з’явиться voiceprint і **одразу активний** (hot-reload, рестарт не потрібен).
4. У Home Assistant: **Settings → Devices & services → Add integration → Wyoming Protocol** → хост `homeassistant` (або IP), порт **10350**.
5. У Assist pipeline оберіть STT = **Voice Match**.

## Запис і enrollment у веб-інтерфейсі

1. **Спікер** — оберіть існуючого або введіть нове ім’я (`a-z`, `0-9`, `_`, `-`, до 32 символів).
2. **Запис з мікрофона**: Запис → говоріть 3–10 сек → Стоп → Перевірити → Зберегти як WAV.
3. Або **Файли з диска** — будь-який поширений аудіоформат; сервер конвертує в WAV 16 kHz mono.
4. **Перевірити всі зразки** — оцінка тривалості, sample rate, гучності (peak/rms), кліпування.
5. Залиште **3–5** зразків зі статусом OK.
6. **Enrollment** — створює voiceprint (файл у `/data/voiceprints/`). Voiceprint **активується одразу** — рестарт аддона не потрібен.

Без Enrollment voiceprint не з’явиться. Після Enrollment або видалення voiceprint зміни підхоплюються автоматично (hot-reload).

Якщо ви записали зразки і закриваєте вкладку без Enrollment — браузер може запитати підтвердження (захист від втрати роботи).

## Будь-який голос (режим проксі)

У Configuration вимкніть **require_speaker_match** (`Вимагати збіг голосу`).  
Тоді аддон не відхиляє чужі голоси і працює як звичайний проксі з очищенням сегментів (залежно від порогів).

## Параметри Configuration

Назви параметрів у схемі — англійською; у інтерфейсі HA (залежно від мови) показуються українські підписи з `translations/`.

| Параметр (англ.) | Українською | Опис | За замовчуванням |
|------------------|-------------|------|------------------|
| **upstream_uri** | Адреса Wyoming STT | Куди слати очищене аудіо. Формат `tcp://хост:порт` | `tcp://homeassistant:10300` |
| **verify_threshold** | Поріг верифікації голосу | Схожість голосу 0–1. Вище = суворіше | `0.35` |
| **extraction_threshold** | Поріг виділення сегментів | Відсікає ТБ/чужі голоси перед STT | `0.30` |
| **max_verify_seconds** | Макс. тривалість першої перевірки | Секунди аудіо для першої перевірки | `5.0` |
| **verify_window_seconds** | Розмір ковзного вікна | Вікно для повторної перевірки (сек) | `3.0` |
| **verify_step_seconds** | Крок ковзного вікна | Крок зміщення вікна (сек) | `1.5` |
| **stt_languages** | Мови розпізнавання | Мови через кому, напр. `uk,ru` | `uk,ru` |
| **tag_speaker** | Додавати ім’я мовця до тексту | Перед транскриптом додається `[ім’я]` | `false` |
| **require_speaker_match** | Вимагати збіг голосу | `true` — чужий голос не проходить | `true` |
| **save_rejected** | Зберігати відхилені записи | Для діагностики порогів | `false` |
| **log_level** | Рівень логування | `DEBUG` / `INFO` / `WARNING` / `ERROR` | `INFO` |

### Рекомендовані пороги

| Ситуація | verify_threshold | extraction_threshold |
|----------|------------------|----------------------|
| За замовчуванням | 0.35 | 0.30 |
| Часто відхиляє «мене» | 0.28–0.32 | 0.25–0.28 |
| Чужий голос проходить | 0.45–0.55 | 0.35–0.40 |
| Обрізає ваші слова | — | знизьте до 0.25–0.28 |

Пороги впливають лише на те, **хто** проходить і наскільки чиститься фон. На якість розпізнавання тексту впливає upstream STT (модель, мови).

## Порт і інтеграція

- **10350/tcp** — Wyoming Protocol (додайте інтеграцію в HA).
- Ingress UI — бічна панель **Voice Match** (запис, enrollment, scan).

## Типові проблеми

| Проблема | Що спробувати |
|----------|----------------|
| Чужий голос проходить | Підвищити `verify_threshold`, перезаписати зразки |
| Власний голос відхиляється | Знизити `verify_threshold`, більше OK-зразків, Enrollment |
| Обрізає слова | Знизити `extraction_threshold` |
| Після Enrollment нічого не змінилось | Зачекайте 1–2 сек (hot-reload); перевірте логи |
| Немає upstream | Сканувати в UI або `tcp://homeassistant:10300` |

## Дані

- Зразки: `/data/enrollment/<speaker>/`
- Voiceprints: `/data/voiceprints/<speaker>.npy`
- Моделі кешуються в `/data/models` та `/data/hf_cache`
