# Changelog

## 1.5.1

- Кнопки видалення: «🗑 Видалити» замість «×», вирівняні в один стовпчик
- Restart: постійний блок внизу сторінки (авто-restart + посилання на сторінку аддона)
- Попередження при виході, якщо є незавершений запис або зразки без Enrollment

- Файли з диска також конвертуються в WAV
