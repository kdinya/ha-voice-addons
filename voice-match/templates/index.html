0. Калібрування тиші

Живий рівень звуку (RMS). Використовуйте, щоб підібрати Поріг тиші у Configuration аддона (50–400). Кнопка «Виміряти тишу» 3 с слухає фон і показує поточне / максимальне значення.

0100200300400+
Зараз: — Макс: — Мікрофон вимкнено

Рекомендація: поставте Поріг тиші трохи вище за «Макс» під час вимірювання фону (наприклад макс 120 → поріг 150–180).

1. Пошук Wyoming STT

Поточний upstream: —. Якщо порожньо — натисніть «Сканувати» і скопіюйте URI у Configuration аддона.

2. Спікер

Оберіть існуючого спікера зі списку або введіть нове ім’я латиницею (a–z, 0–9, _, −).

3. Запис з мікрофона → WAV

Запис → Стоп → Перевірити (тривалість, гучність) → Зберегти або Видалити. Бажано 3–10 секунд чистої мови.

4. Файли з диска

Будь-який формат (wav, flac, mp3, ogg, webm…) → на сервері конвертується в WAV 16 kHz mono.
