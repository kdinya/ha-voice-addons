## 2. Core Architecture & Strict Invariants

1. **Voice Match — Early Endpoint & Silence Handling**:
   - Never strip silence detection (`silence_threshold`), short-noise/cough fast-paths, or early session termination.
   - When incoming stream is pure silence or short noise, return an empty `Transcript(text="")` immediately and terminate the session cleanly so client satellites do not hang waiting for 30–60 second VAD timeouts.
   - Maintain `_MODEL_LOCK` serialization during ECAPA-TDNN inference on CPU to prevent memory race conditions.

2. **Autonomous Dockerfile & Volume Management**:
   - `voice-match/Dockerfile` must build self-contained from standard `python:3.11-slim` without relying on unmaintained third-party base images.
   - PyTorch CPU wheels must be installed via the unified CPU index (`--index-url https://download.pytorch.org/whl/cpu`) supporting both `amd64` and `aarch64`.
   - Hugging Face cache and downloaded models must strictly map under persistent data storage (`/data/models`, `/data/hf_cache`) to prevent redundant downloads across container restarts.

3. **Wyoming Protocol & Hot-Reload Invariant**:
   - Voiceprints reside in `/data/voiceprints`.
   - Saving or deleting speaker samples via the Ingress WebUI must hot-reload speaker embeddings in memory without requiring a full container restart.
   - Adhere strictly to the Wyoming event sequence: `Transcribe` -> `AudioStart` -> `AudioChunk` -> `AudioStop` -> `Transcript`.

4. **Wyoming OpenAI STT — Parameter Sanitization**:
   - All options from `/data/options.json` inside `wyoming-openai-stt/entrypoint.sh` must be parsed inside an isolated Python sub-process without raw string interpolation into shell commands (mitigating shell injection).
   - Default Ukrainian language preference (`uk`) must be maintained in the Whisper prompt for ambiguous utterances.

5. **Security & Input Validation**:
   - Speaker names in `webui.py` must be strictly sanitized against path traversal (`..`, `/`, `\`).
   - Audio inspection (`analyze_wav`) must safely handle raw streams and invalid wave headers without throwing unhandled exceptions.

6. **Full Localization (i18n)**:
   - Configuration options in `config.yaml` must have corresponding definitions across `translations/uk.yaml`, `translations/en.yaml`, and `translations/ru.yaml`.
   - WebUI text and status messages must support clean UTF-8 Ukrainian output.
